Dewlune · headless WooCommerce store
Headless store · Next.js + WooCommerce

Dewlune

A skincare store where the shopping experience is Next.js and the products, cart and checkout come from WordPress + WooCommerce through the Store API.

  • Real cart and cash-on-delivery checkout that creates orders in WooCommerce admin
  • Liquid-glass hero and footer built with Plasma UI (WebGL), desktop only
  • Docker WordPress setup, WP-CLI seeder and a custom must-use plugin
Next.js 16TypeScriptTailwindWooCommerceWordPressPHPDocker
Live demo Code
Read case study
The brief
Show that I can work on both sides of a modern store: a fast React front end, and the WordPress + WooCommerce backend that most Pakistani brands already run on.
What I did
Built the storefront in Next.js 16 with cached catalog pages, a bag drawer, filters and an accessible checkout. Cart and checkout calls go through Next.js server routes that keep WooCommerce's cart token in an httpOnly cookie, so the browser never talks to WordPress directly. On the WordPress side I wrote a Docker setup, a WP-CLI script that seeds settings, delivery rules and products, and a must-use plugin that adapts WooCommerce's address rules for Pakistan.
The result
Orders placed in the store show up in WooCommerce admin with the right items, delivery and payment method. Without a backend, the same code runs on bundled demo data, so it can be hosted for free.
